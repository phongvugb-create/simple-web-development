Web Technology

HTML là viết tắt của HyperText Markup Language, ngôn ngữ đánh dấu được sử dụng để xây dựng cấu trúc trang web. HTML giúp trình duyệt tổ chức văn bản, hình ảnh, liên kết và các thành phần nội dung. Khi kết hợp HTML với CSS và JavaScript, chúng ta có thể tạo nên những trang web đẹp mắt và có tính tương tác.

C Programming

C là ngôn ngữ lập trình thủ tục được phát triển bởi Dennis Ritchie. Ngôn ngữ này cung cấp khả năng làm việc với bộ nhớ ở mức thấp và thường được sử dụng trong phát triển hệ điều hành, trình biên dịch và các phần mềm hệ thống. Học C cũng giúp người học hiểu rõ hơn về biến, vòng lặp, hàm và cách máy tính xử lý dữ liệu.

Java Programming

Java là ngôn ngữ lập trình hướng đối tượng phổ biến. Mã Java thường được biên dịch thành bytecode và chạy trên Java Virtual Machine (JVM), giúp chương trình có thể hoạt động trên nhiều nền tảng hỗ trợ JVM. Java được sử dụng trong phát triển ứng dụng doanh nghiệp, phần mềm máy chủ và nhiều loại ứng dụng khác.

Những gì bạn sẽ học

HTML

Xây dựng cấu trúc trang web bằng các thẻ và phần tử HTML.

Flexbox

Responsive

Tối ưu bố cục để trang web hiển thị tốt trên nhiều màn hình.
